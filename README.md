# 📐 Regra de Cramer em Python

Projeto desenvolvido em Python para calcular sistemas lineares
utilizando a Regra de Cramer.

## 📌 Sobre o projeto

O programa permite informar uma matriz quadrada e os termos
independentes de um sistema linear.

A partir desses valores, o programa calcula:

- Determinante principal (D)
- Determinantes D1, D2, D3...
- Valores das incógnitas x1, x2, x3...

## ⚙️ Funcionalidades

- Validação da quantidade de linhas e colunas
- Verificação de matriz quadrada
- Aceita valores positivos, negativos e zero
- Tratamento de entradas inválidas
- Cálculo do determinante
- Aplicação da Regra de Cramer
